## 🧠 Overview
The Smart Study Assistant is an API-driven AI project that integrates **Natural Language Processing (NLP)** and **Computer Vision (CV)** to help students learn effectively.  

It allows users to:
- Ask study questions and get AI-generated answers
- Get topic explanations and summaries
- Upload handwritten or printed images to extract text (OCR)
- Automatically grade short answers
- View AI performance metrics (latency, accuracy, etc.)
